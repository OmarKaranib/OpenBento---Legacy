# Frontend design reference

Use the user's product, audience, existing design, and technical context to choose an appropriate visual direction. For a focused change, work directly within the established interface. For new visual exploration, consider typography, hierarchy, color, spacing, motion, and a distinctive composition together.

- Implement working behavior and integrate with the actual application architecture.
- Choose fonts, colors, component patterns, and libraries for the product; no font family, framework, or aesthetic is categorically prohibited.
- Use consistent tokens and meaningful hierarchy. Refine spacing, alignment, responsive behavior, focus, and readability.
- Use motion and decorative effects when they help the intended experience; preserve reduced-motion support and interaction performance.
- Match complexity to the visual goal. Simple interfaces do not need elaborate effects or extra abstractions.
- Validate the affected behavior and presentation proportionately. A design-system document, special planning phase, or redesign is not a prerequisite.
